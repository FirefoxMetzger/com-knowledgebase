# Topic index (newsletter → wiki)

**Purpose:** The compiled **topic layer** turns `raw/emails/newsletters/*.md` into short, skimmable notes so an agent can (1) see what the inbox actually covered, (2) jump to the right exports, and (3) know what still needs a primary source outside the digests.

**Conventions:** Topic pages with an **`apr-2026` (or date-range) suffix** cover the **2026-04-13**–**2026-04-22** capture window; when new raw lands, add dated suffixes or fold updates into a newer note. [[ai-newsletter-inbox]] states counts and scope; the canonical file list is [[../sources/newsletters-catalog|newsletters-catalog]].
